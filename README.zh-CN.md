# Weather Pet · 离线专注宠物

**选一只宠物，写下一件小事，慢慢开始。**

[English](README.md)

![天气宠物](docs/overview.jpg)

由原来的天气宠物路演稿改成真正可用的小应用：四个水彩场景、三只宠物、
本地待办、5/25/45 分钟专注计时、暂停与恢复、刷新后保存偏好与任务。
时间和日期来自当前设备，计时使用绝对截止时间以应对后台标签页暂停。

直接打开 `index.html` 即可体验，也可以运行：

```bash
python -m http.server 8000 --bind 127.0.0.1
```

再打开 http://127.0.0.1:8000。页面不调用外部服务，没有账号与云同步。
浏览器允许时，任务保存在本地存储中；清理网站数据会删除任务。

温度是明确标记的模拟场景数值，不是实时天气。手机外框只是展示，
当前没有原生 iOS 桌面组件或系统日历接入。水彩宠物图片由 AI 生成。

开发测试：Node.js 22+ 下运行 `npm test`，6 项测试通过；
已在浏览器验证添加任务、切换场景、暂停和刷新恢复。MIT 许可。
